# <Sanjay's Portfolio/> 🚀

A premium, high-performance portfolio website built with **React**, **Framer Motion**, and **tsParticles**. Designed with a focus on modern aesthetics, interactive animations, and a seamless user experience.

![Portfolio Preview](https://via.placeholder.com/1200x600?text=Sanjay's+Portfolio+Preview)

## ✨ Features

- **Premium Design System**: Dark mode by default with an "Electric Violet & Cyber Cyan" gradient palette.
- **Glassmorphism**: Sleek, frosted-glass UI components with back-drop blur effects.
- **Advanced Animations**: 
  - **Preloader**: Animated logo reveal and progress bar on first load.
  - **Hero Section**: Interactive particle background and dynamic typing effects.
  - **Scroll Reveal**: Elements fade and slide into view as you scroll.
  - **Custom Cursor**: A spring-animated cursor that follows the user's interaction.
- **Filterable Projects**: Categorized project gallery (AI, Full-Stack, Web3) with smooth transitions.
- **Responsive Design**: Fully optimized for Mobile, Tablet, and Desktop users.
- **SEO Optimized**: Meta tags and structured data for better search visibility.

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Background Effects**: [tsParticles](https://particles.js.org/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/) + [Iconify](https://iconify.design/)
- **Routing**: [React Router Dom](https://reactrouter.com/)
- **Styling**: Vanilla CSS (Modern CSS Variables & Modules)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sanjuthecoder/portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
